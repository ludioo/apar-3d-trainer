# APAR 3D Trainer & Configurator

Interactive 3D fire extinguisher (APAR) configurator and PASS training demo — vanilla JavaScript, three.js, Vite.

## Setup

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
npm run preview
```
