# U6 — Performance pass + LHCI mobile

## Goal

Naikkan Lighthouse mobile Performance (LHCI 3-run median) menuju ≥80 tanpa melonggarkan `lighthouserc.cjs` / budget DPR–tekstur. Baseline live 36; historis T4.25 median 47.

## Grill decisions (self-answered)

| Q | Choice | Why |
|---|---|---|
| Split Train/Quiz/Results? | Ya, dynamic `import()` on first `#train`/`#results` | Potong parse/eval main chunk; LHCI di `/` Configure tidak fetch chunk itu |
| Preload idle setelah splash? | Tidak | LH menunggu network idle — preload menggerus skor |
| PMREM coarse | 64 (was 128) | Usulan T4.25; hemat GPU sync; visual silver tetap RoomEnvironment |
| Gate splash on PMREM? | Tidak — `prepareModel` hanya `compileAsync` | Env tetap load paralel; splash dismiss lebih awal |
| Dynamic `loader.js`? | Ya | GLTF/DRACO/KTX2 addons keluar entry |
| PDF helpers | Dynamic di `exportPdf` | Lepas `quiz.json`/`emergency.json` dari boot |
| Naikkan DPR/tekstur? | Tidak | Budget + skor LH |
| Assert LHCI? | Tetap ≥0.8 / A11y ≥0.9 | Acceptance: hijau atau blocker file/fungsi di known-issues |

## Approach

1. Ukur baseline `npm run lhci` (3 run / median) sebelum ubah kode.
2. Pecah boot: lazy train/quiz/results (+ attempts); dynamic loader; dynamic pdf-common; PMREM 64 coarse; `prepareModel` tanpa await env.
3. Driver / jsPDF / debug / Umami tetap lazy.
4. Ulang LHCI; jika median &lt;80 dokumentasikan blocker konkret; budget assert tidak dilonggarkan.
5. Lint / test / e2e / build harus hijau.

Rejected: naikkan resolusi; longgarkan assert; preload fitur setelah splash; ganti RoomEnvironment untuk skor saja.
