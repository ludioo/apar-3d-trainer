# Plan U2 — Layout polish mobile + desktop

## Goal
Perbaiki isu mobile-ux-spec #3–#6: viewport-fit + safe-area, short-landscape canvas ≥ ~40% vh (bukan 16px), topbar/emergency compact, SE peek/half scrollable, tanpa regresi desktop 360px.

## Approach
1. Meta `viewport-fit=cover`; `env(safe-area-inset-*)` pada topbar/sheet/toast; `html,body` overflow hidden; prefer `dvh` (sudah) + `svh` fallback di token sheet bila berguna.
2. Mode short-landscape (`h ≤ 500` && `w < 1024`): class `is-short-landscape` di `html`; default snap **peek**; `--sheet-min-h` lebih rendah; emergency keluar dari flow topbar (absolute di bawah header) + hide details.
3. Mobile portrait: sembunyikan `.emergency-chrome__details` (chips `tel:` tetap); panel body tetap scroll.
4. Desktop ≥1024: tidak ubah `--panel-w` / clamp hotspot; verifikasi bounding box.

**Rejected:** ganti ke `pure-web-bottom-sheet` (out of scope Fase 5).
