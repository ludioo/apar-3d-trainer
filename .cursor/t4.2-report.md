Tanggal: 28 Oktober 2026 (Asia/Jakarta). Branch kerja develop. Acceptance final diterima Barkah; task/lima checklist selesai dan commit/push ke develop diotorisasi. T4.3 belum dimulai, main/deploy produksi tidak diotorisasi.

## Keputusan dan hasil

Validasi Q1–Q6 lalu planning disetujui Barkah. Perluas pointer drag/snap existing tanpa dependency, menggantikan usulan pure-web-bottom-sheet/CSS scroll-snap. Library tidak dipasang/diprototipe; batas Safari >=18.2 dari README resmi adalah alasan mempertahankan mekanisme existing, bukan klaim kompatibilitas fisik sudah diuji.

- Sheet shared Configure/Train/kuis/Results, mobile <1024px: peek 25%, half 50%, full 75%, default half. Minimum 176px dan maksimum ruang di bawah topbar dengan jarak 16px. Tinggi sama dilewati pada siklus layar pendek, tanpa membuang preferensi snap saat resize.
- Drag hanya handle, nearest snap pada release, seri memilih lebih rendah. Tap/Enter/Space pada click menggilir peek→half→full→peek; koreksi anti klik jawaban T2.3 dipertahankan. Cancel/lost capture kembali ke pilihan sebelumnya.
- State hanya memori, tetap saat tab/bahasa/hotspot/About/breakpoint berubah; reload half. Desktop panel kanan/canvas full-bleed tetap.
- ResizeObserver panel memasok tinggi aktual untuk batas kanvas selama drag/transisi; observer scene/pin existing memperbarui renderer/aspek/proyeksi. Tidak mengubah posisi kamera/framing default, resource APAR, atau menambah loop permanen.
- VisualViewport scale=1 memperbarui tinggi/inset bawah keyboard; zoom halaman tidak dianggap keyboard. Fallback innerHeight saat API tidak tersedia. Label EN/ID menyebut posisi/aksi berikutnya; event sheet:change menyinkronkan bootstrap, sheet tetap bisa diimport self-check Node.

## Probe gagal dan batas pengujian

Selector close awal keliru .hotspot-card__close dan agent powder; diperbaiki ke .hotspot-info__close/powder_abc. Wrapper awal menyuntikkan kode ke marker string wrapper bersarang; diubah menjadi wrapper langsung. Helper snap Results semula memakai tap di context tanpa hasTouch; pemilihan posisi matriks memakai click, skenario touch native terpisah dipertahankan. Run gagal bukan PASS; JSON awal dipertahankan dengan suffix initial/probe2/touch-initial.

Pelepasan pointer capture eksplisit pada revisi awal dibuang untuk mengikuti perilaku otomatis existing. Kegagalan touch tidak boleh dinyatakan selesai karena itu saja: raw CDP swipe diikuti tap instan Playwright pada jeda 300ms masih menghasilkan pointerup tanpa browser click. Jeda probe 800ms stabil 12 siklus, penyebab browser/protokol belum diisolasi. Gesture cepat HP fisik tetap perlu acceptance. Tidak menambah workaround/timer atau memindah tap ke pointerup yang dapat mengembalikan bug kuis.

Safari/iOS, Firefox, HP fisik, AT/screen reader, keyboard OS, Lighthouse/4G dan live produksi belum diuji. Favicon 404 existing serta fault jaringan/storage/model yang disengaja dalam regresi dikecualikan, tanpa klaim jaringan fault tersebut normal. Tidak ada pageerror/console error tak terduga pada run final.
