## Perubahan dan hasil

Tiga file aplikasi berubah: `src/ui/training.js`, `src/ui/training.css`, `src/ui/quiz.css`. Fase langkah PASS dan soal/feedback memakai flex kolom, body flex1 0 auto, nav flex:none/sticky bottom. Root scroll dan lifecycle/API existing tetap; tidak membuat scroll container, observer atau loop baru. Padding bawah PASS memakai ukuran footer dari ResizeObserver existing; kuis mempertahankan padding bawahnya.

Petunjuk/status PASS menempati sel grid yang sama, menyisakan tinggi terbesar keduanya. Visibility menyembunyikan yang tidak aktif tanpa menghapus ruang. Tujuan Sweep juga mempertahankan ruang setelah selesai. Overflow anchoring PASS dimatikan. Border opsi kuis tetap2px agar wrapping/tinggi tidak berubah sesudah memilih. Feedback tetap langsung setelah jawaban terpilih, Next manual, fokus/scroll existing dan snap pilihan pengguna tetap. Opsi di bawah feedback boleh terdorong sesuai T4.3. Intro/ringkasan tidak dipaksa mengisi ruang.

## Alat dan batas

Browser Use doctor gagal daemon/koneksi; memakai Chrome/Playwright existing tanpa install. Probe selector disclaimer awal ambigu, diperbaiki `.last()`. Regresi kuis lama menganggap ketiga nama snap selalu dapat dicapai; wrapper kini membandingkan tinggi efektif seperti helper T4.11 existing, tanpa memalsukan state aplikasi.40 keadaan tetap dijalankan;10 permintaan setara dicatat. Probe fokus Escape kini menunggu event close/fokus aktual. Probe swipe awal dimulai di batas bawah setelah wheel, lalu diperbaiki dengan reset scroll dan konteks touch. Bukti gagal disimpan di `dev-probe-selector.json`, `layout-probe-collapsed-snaps.json`, `input-probe-close.json`, `input-probe-scroll-boundary.json` dalam folder `t4.16`; semuanya tidak dihitung PASS.

Matriks utama memakai reduced motion dan token font100/200%, bukan zoom OS. Regresi Squeeze serta input tambahan memakai motion normal dan reduced motion. AX tree Chrome membuktikan elemen inactive diabaikan, bukan pengujian screen reader manusia. HP fisik, AT, Safari/Firefox, zoom OS, keyboard virtual, Lighthouse/4G/FPS baru belum diuji. Layar pendek/teks besar memerlukan scroll; model/framing/tinggi sheet tidak diperluas oleh task ini. Warning bundle utama>500KB existing tetap.
