# T2.2 design gate, 28 Okt 2026

Cakupan: efek api, garis bidik, semprotan dan framing/lifecycle latihan. Industrial Safety Studio, ENERGY 1 / RHYTHM 1 / MOTION 2, mengikuti validasi Q1–Q5 dan rencana yang disetujui Barkah. Api menunjukkan sasaran; semprotan menunjukkan hubungan tahan/slider dengan nozzle; perubahan ukuran menunjukkan lintasan yang berhasil. Warna berasal dari token existing, tanpa perubahan shell/layout atau copy K3.

- Hard Gate PASS (R-02/03): tidak ada teks UI baru; K3 existing persis sumber melalui self-check. Matriks 40 viewport/bahasa/teks/snap memastikan tidak ada overflow, slider dan footer dapat di-hit-test. Api muat pada kanvas sheet ringkas; sheet diperbesar sengaja tetap pilihan pengguna dan dapat menutup stage, mengikuti alur existing.
- Hard Gate PASS (R-17/18/23/36/38): tidak membuat statistik/testimoni/klaim kompetensi. Efek prosedural dibuat sesuai permintaan eksplisit, tercatat sebagai kode proyek MIT; tanpa layanan/aset unduhan. FPS dilaporkan sebagai sampel desktop/headless/HP emulasi, tidak mengklaim HP fisik.
- Hard Gate PASS (R-24/26/28): Start, Pull/Aim, hold, slider, Back/Next/Finish, Skip, Refocus, Repeat, bahasa, route dan About benar-benar diuji. Telepon/link sumber existing diuji regresi. Tidak ada FAQ atau navigasi baru.
- Hard Gate PASS (R-25): pengukuran token aktual pada preview produksi menghasilkan teks/surface 15,87:1, muted 6,77:1, ink/accent 12,01:1, fokus/surface 11,21:1 (`t2.2-contrast.json`). Warna api bersifat ilustrasi, status/siklus tetap tersedia sebagai teks; efek tidak membawa teks atau kontrol baru.
- Hard Gate PASS (R-27/32): loading/model gagal/Retry, storage gagal, intro/reset dan alur Skip diuji. Keyboard Space/Enter dan slider Arrow/Home/End, mouse/touch, Escape About serta target tuas/nozzle berfungsi. Target/control existing minimal 44px. Reduced motion memakai gambar statis serta perubahan langsung, tanpa flicker/loop partikel.
- Hard Gate PASS (R-33/34/35): perubahan aplikasi ditulis langsung melalui apply_patch, tidak memakai skrip pengganti source/CSS. Skrip regresi hanya menyalin alat uji existing dengan nama bukti T2.2. Tidak ada tema baru. Check/build dan QA dev/produksi lolos; screenshot final tanpa marker debug ditinjau.
- Purpose-Gate PASS (R-01/04/06/07/08/09/10/12/13/19/31): gradasi/blur hanya di tekstur kecil untuk bentuk nyala/semprotan; garis menunjukkan sasaran pangkal, bukan ornamen. Api berwarna hangat untuk identifikasi, putih untuk agent ABC dan kuning untuk bidik/aksi mengikuti token. Tidak menambah ikon, badge, grid, panel, shadow, blur UI atau font. Gerak api hanya saat stage aktif/terlihat; semprotan hanya saat input, seluruh efek berhenti pada interupsi/exit/padam dan reduced motion statis.
- Liveliness PASS (R-20/37): APAR tetap fokus utama, ruang di kiri panel desktop/di atas sheet HP membingkai alat dan sasaran bersama. Angka langkah/target dan aksen safety existing menghubungkan tindakan dengan bagian. Screenshot `t2.2-preview-desktop.png`, `t2.2-preview-mobile.png`, `t2.2-preview-landscape.png` serta versi Sweep diperiksa.
- Craftsmanship/Quality Locks PASS (C-1..C-5, R-05/11/15/16/21/29/30): dua batch Points (24/72) dan garis, buffer dipakai ulang, dua tekstur 64×64, satu scene/renderer existing. Rangkaian hitungan tetap T2.1, Skip tidak memalsukan progres dan Back tidak menyalakan ulang api. Framing kanan depan memperbaiki oklusi target tuas; ukuran sprite dan posisi api sama-sama mengecil. Resource stabil setelah mode berulang, 3 draw call tambahan, renderer diam setelah pause/padam/Skip. Tidak menambah framework/dependency atau fitur T2.3.
