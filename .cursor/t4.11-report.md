## Perubahan dan alasan

- Ringkasan Train dan kartu Results menampilkan copy yang sama dekat skor: ID `Ambang lulus: ≥75% (6/8)` / EN `Passing score: ≥75% (6/8)`. Status, skor dan format existing dipertahankan: 5/8=62,5% ID/62.5% EN, 6/8 lulus.
- UI kuis existing menambahkan section berjudul dan ordered list delapan soal, sebelum tombol aksi. Setiap item mempunyai pertanyaan, jawaban pengguna dan Benar/Salah; item salah juga mempunyai jawaban benar. Daftar mengikuti attempt sesi, bukan storage, sehingga gagal simpan tetap dapat direview.
- Label choice dan judul hotspot mengikuti quiz.json/hotspots.json. ID: Pin pengaman, Tuas, Selang & nozzle, Indikator tekanan, Label, Tabung; padanan EN mengikuti content-and-assets. Pilihan/pin saat menjawab tetap Part/Bagian N agar tidak membocorkan jawaban. Tabel Results tetap existing dan hanya memakai hasil tersimpan terbaru.
- Tiga key UI baru pada kedua bahasa. Nilai jawaban dimasukkan melalui textContent; bukan HTML. Review dibersihkan di luar fase summary. Ganti bahasa merender ulang dari ID yang sama tanpa menulis ulang attempt. Tidak ada API publik, skema/migrasi/storage, teks K3, aturan penilaian, PDF, mesh, kamera, dependency, aset atau loop baru.
- Arah Industrial Safety Studio dipertahankan, ENERGY 1 / RHYTHM 1 / MOTION 1. Skor menjadi fokus; heading dan ordered list menjaga urutan baca. Font/warna/spacing/border memakai token existing, dengan status teks selain warna. Daftar datar sesuai isi delapan soal, tanpa navigasi atau animasi baru.

Click-through yang direkam:

- Mulai latihan, empat Lewati/Berikutnya, Ikuti kuis: membuka kuis nyata dari PASS; bukan injeksi ringkasan.
- Pilihan soal melalui Enter dan Next/Lihat skor melalui Space: jawaban pertama terkunci, feedback lalu ringkasan yang benar. Regresi juga memeriksa kedua pin3D, orbit, Reset view, About/Escape dan interupsi.
- EN/ID: pertanyaan/jawaban/status/ambang berubah tanpa reload, skor/attempt sama.
- Lihat hasil dan tab Latihan: kartu Results membaca hasil tersimpan; kembali membuka review sesi yang sama tanpa menambah attempt.
- Ulangi kuis melalui Space: review lama dibersihkan dan q1 belum dijawab. Kembali ke latihan: kartu latihan selesai; Ikuti kuis berikutnya memulai sesi baru. Refresh membuka intro PASS.
- Handle mobile via native touch: mengubah tinggi sheet; seluruh heading dan akhir item1-8 serta tiga tombol akhir di-hit-test saat scroll, pada100/200% teks. Regresi matriks memakai keyboard pada handle agar stabil setelah resize; sentuhan diuji terpisah pada390px.
- Results: tautan Train/Kelola konfigurasi, edit nama/Enter/blur, dialog Clear/Batal/Escape/konfirmasi/retry, kontak/disclaimer dan scrolling diperiksa regresi existing.

## Probe awal, kontras, dan batas

- `browser-use doctor` gagal koneksi/daemon; memakai Playwright existing dari cache runtime dan Chrome lokal Program Files. Tidak memasang atau mengunduh library baru.
- Probe khusus awal menuntut nama full saat half/full berimpit pada390px/font200. Wrapper regresi lama juga menuntut nama snap yang sama serta klik pada layout yang baru di-resize. Ini asumsi probe yang tidak sesuai mekanisme sheet existing. Helper khusus kini membandingkan tinggi; helper regresi menunggu resize dan memakai Enter, dengan alias hanya bila perhitungan tinggi persis sama. Assertions konten/hit-test tetap dijalankan pada setiap permintaan keadaan. Kegagalan regresi awal dipertahankan di `t4.11-quiz-initial-qa.json` dan `t4.11-results-initial-qa.json`; tidak dihitung PASS. Run final diulang sampai lolos; tidak mengubah sheet aplikasi.
- Kontras pada surface-solid: text15,87:1, success7,86:1, danger5,77:1 (JSON QA khusus). Panel transparan92% juga dihitung pada latar putih terburuk, komposit RGB40,64/43,4/48: text12,72:1, muted5,43:1, success6,30:1, danger4,63:1. Seluruh teks baru melewati AA4,5:1; font bukan satu-satunya pembeda status.
- Warning build chunk utama>500KB dan warning presisi shader headless existing tetap. Laporan final pageerror/console error tak terduga kosong; favicon404 existing dikecualikan oleh helper. Tidak mengklaim warning/masalah existing proyek lain telah diselesaikan.
- Font200 diuji melalui pembesaran token, bukan zoom/setting OS. Pada390px/header besar, half/full berimpit; pada landscape/ruang pendek, lebih banyak posisi dapat berimpit. Konten dapat digulir, tidak harus muat sekaligus. Pada screenshot font200, header mengambil banyak ruang dan skor terbungkus ke dua baris; teks tetap terbaca melalui scroll.
- Belum menguji HP fisik, Safari/Firefox, AT/screen reader, zoom OS, Lighthouse/4G/FPS baru. Angka ukuran bundle bukan klaim target performa tercapai. Data pada screenshot adalah attempt QA yang dijalankan di konteks browser terpisah, bukan riwayat pengguna.
