## Perubahan dan alasan

- SVG mandiri viewBox64×64 menggambarkan tabung, tuas dan selang APAR. Dua warna #FFC629/#0E1013 mengikuti token Industrial Safety Studio yang disetujui. Bentuk tebal dan tanpa teks menjaga keterbacaan16px; tidak memakai font/script/animasi/referensi eksternal.
- ICO dibuat dari SVG yang sama dengan Chrome/Playwright existing, dikemas sebagai tiga PNG RGBA16/32/48px dengan Buffer Node. Helper `t4.14-icon.cjs` dapat dijalankan ulang; bukan proses build tambahan. PNG-in-ICO ditujukan untuk browser modern, tanpa klaim kompatibilitas browser legacy.
- Dua link icon pada head: ICO terlebih dahulu, kemudian SVG bertipe image/svg+xml dan sizes=any. Path root mengikuti konfigurasi Vite/deployment existing; tiga mode aplikasi tetap berupa hash.
- Tidak ada dependency, kode runtime, i18n, skema/storage, analytics, model, CSS, OG atau PWA baru. Selain dua link head, perubahan aplikasi hanya dua aset statis. Semua perubahan lokal di luar task dipertahankan.
