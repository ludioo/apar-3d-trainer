## Baseline dan perubahan

- Baseline validasi read-only: mouse 1280×900 dan native CDP touch 390×844 pada tombol panel berhasil mengaktifkan Next sesudah hold satu detik. Lepas 300ms membatalkan, ulang tahan 1250ms berhasil. Bug timer awal belum tereproduksi; tidak mengklaim akar masalah ditemukan atau kegagalan pada perangkat tertentu telah diperbaiki.
- Gap pasti: callback progres hanya memperbarui target bernomor 3D; tombol panel tidak punya ring. complete juga memanggil cancel gesture yang mengembalikan ring target ke nol.
- Perubahan aplikasi hanya tiga file: src/features/training/training.js, src/ui/training.js dan src/ui/training.css. Span label dan ring panel dibuat sekali, ring 24×24px memakai token accent/surface-solid/text-muted. Ruang ring tetap sepanjang hold; label bilingual existing dan ring aria-hidden.
- Satu callback meneruskan progres ke panel dan target 3D. Visual penuh berasal dari status sesi done, sehingga tetap 360deg setelah release/blur/sync/bahasa/Back. Skip tetap nol. Pembaruan visual saat sync tidak mengubah emisi Sweep; handler/timer 1000ms existing tidak diubah.
- Tombol hold memakai touch-action:none/user-select:none. Progres fungsional tetap berjalan pada reduced motion; tidak menambah animasi dekoratif, timer, rAF, dependency, aset, API publik, storage, analytics atau perubahan K3.

## Probe gagal dan warning

- browser-use doctor gagal daemon/koneksi. QA menggunakan Chrome di Program Files dan Playwright yang sudah tersedia; tidak menginstal dependency baru.
- t4.8-production-initial-qa.json dan t4.8-production-capture-initial-qa.json menyimpan kegagalan probe lost capture. setPointerCapture awal masih pending sampai event pointer selanjutnya; release sebelum gotpointercapture tidak menghasilkan lostpointercapture. Ini tidak membuktikan handler aplikasi rusak. Helper final menggerakkan mouse 1px setelah down agar capture aktif, lalu release dan pointermove menghasilkan lostpointercapture dan membatalkan hold. Urutan native terekam pada t4.8-capture-probe.txt; script probe disimpan agar dapat diulang.
- t4.8-training-initial-qa.json berhenti pada kegagalan navigasi HTTP saat membuka konteks reduced motion setelah delapan kelompok PASS. Penyebab belum diisolasi; build preview sempat diperbarui selama run awal, tetapi tidak diklaim penyebab pasti. Run final dengan build stabil lolos semua 11 kelompok. Run awal yang gagal tidak dihitung sebagai PASS penuh.
- Dua warning presisi shader tercatat pada laporan khusus final, dan dua pada smoke. Tidak ada pageerror/console error tak terduga pada laporan final; favicon 404 existing dikecualikan seperti harness lama.
- ResizeObserver loop pernah terlihat pada stdout Vite saat validasi baseline; hubungan dengan kegagalan hold belum terbukti. Websocket Vite yang dipantau pada smoke final tidak memuat pesan itu. Ini bukan klaim warning hilang di semua perangkat atau kondisi. Warning bundle >500 KB existing tetap.
