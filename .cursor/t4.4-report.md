# T4.4 - Area tap dan pemisahan hotspot

Pemeriksaan: 30 Oktober 2026 (Asia/Jakarta). Validasi Q1-Q3 dan planning disetujui Barkah sebelum implementasi. **Acceptance final diterima 30 Oktober 2026:** Barkah mengonfirmasi sudah mengecek T4.4 dan lolos, meminta task/lima checklist selesai, pembaruan dokumen serta commit/push ke develop. Seluruh catatan historis menunggu acceptance T4.4 ditutup. Check/build dijalankan ulang sebelum commit; browser tidak diuji ulang karena penutupan hanya mengubah dokumentasi. Rincian perangkat/browser pengguna tidak diberikan, sehingga batas QA AI tetap berlaku. Tidak lanjut task berikutnya atau mengubah main/deploy produksi. Perubahan lokal di luar T4.4 tetap dipertahankan.

## Temuan dan perubahan

- Sejak T1.4 tombol hotspot sudah 44x44 CSS px, lingkaran 28px, SPACING 48px/celah hitbox minimal 4px, penempatan layar deterministik dan garis ke anchor asli. Tidak membangun ulang mekanisme yang sudah bekerja.
- Bug nyata: pada desktop 1280x900, buka bagian gauge dari daftar panel. Hitbox handle berada pada x864,04-908,04, sementara panel mulai x904. Titik tepi x906,04/y243,46 mengenai section panel. Bukti `t4.4-panel-before.json/png`.
- Perubahan aplikasi hanya satu baris `src/features/configurator/hotspots.js`: teruskan `panel` existing ke `initHotspotPins`. Batas area dan ResizeObserver existing dipakai seperti kuis. Sesudahnya hitbox handle x848-892, celah terhadap panel 12px; titik x890/y243,46 mengenai tombol handle. Bukti dev `t4.4-panel-after.json/png`, produksi `t4.4-panel-production-after.json/png`.
- Tidak mengubah projectPin/placePin, CSS, data posisi/nomor, pemetaan fisik, teks K3/i18n, mesh/model, kamera/tween, storage, analytics atau dependency. Oklusi tetap berdasarkan anchor 3D sebelum offset layar. Tidak ada API/schema/migrasi baru.

## Perintah yang dapat diulang

Server existing: dev 5198 dan preview 4198, keduanya bind 0.0.0.0. Jalankan server pada terminal terpisah jika belum aktif.

```text
node node_modules/vite/bin/vite.js --host 0.0.0.0 --port 5198 --strictPort
npm run check
npm run build
node node_modules/vite/bin/vite.js preview --host 0.0.0.0 --port 4198 --strictPort
node .cursor/t4.4-panel-probe.cjs http://localhost:4198 production-after
node .cursor/t4.4-check.cjs http://localhost:4198
node .cursor/t4.4-smoke.cjs http://localhost:4198
node .cursor/t4.4-regression.cjs http://localhost:4198 --training --production
node .cursor/t4.4-regression.cjs http://localhost:4198 --squeeze
node .cursor/t4.4-regression.cjs http://localhost:4198
```

Harness memakai Playwright/Chrome existing, tanpa install paket. Wrapper regresi memakai harness lama dengan prefix T4.4 agar tidak menimpa bukti task sebelumnya. Probe `before` adalah rekaman sebelum perubahan, bukan hasil yang diharapkan dari kode sekarang. Flag `--dev` pada pemeriksaan khusus mengganti prefix laporan; `--baseline` mengumpulkan kegagalan geometri untuk diagnosis dan tetap gagal bila ada masalah.

## Probe awal, warning dan batas

- `t4.4-dev-baseline-qa.json` adalah run diagnosis awal yang gagal: menyertakan bug panel, toleransi anchor 0,2px yang terlalu ketat dan keyboard yang memilih pin teroklusi. Jangan dihitung PASS penuh. Probe panel terisolasi membuktikan bug panel sebelum/sesudah.
- Probe final menjeda idle dan menunggu dua frame sebelum pengukuran. OrbitControls menekan event perubahan sangat kecil pada akhir tween; toleransi proyeksi anchor 1 CSS px menghindari salah diagnosis perbedaan subpixel 0,2-0,3px. Ini toleransi alat uji, bukan perubahan posisi model atau event aplikasi. Ujung garis terhadap pusat tombol tetap diperiksa 0,2px.
- Label aksesibel kuis memakai Part/Bagian existing; pemeriksaan nomor tidak memaksakan format judul Configure. Tidak mengubah copy aplikasi.
- browser-use doctor gagal daemon/koneksi, sehingga memakai Playwright/Chrome existing. Warning build chunk >500 KB serta warning presisi shader headless THREE.WebGLProgram tetap dicatat; favicon 404 existing dikecualikan dari unexpected console errors. Tidak mengklaim semua warning hilang.
- HP fisik, Safari/Firefox, screen reader/AT, browser zoom/keyboard OS dan audit Lighthouse/4G/FPS baru belum diuji. Teks 200% dalam regresi adalah pembesaran token panel, bukan zoom browser sebenarnya.
- Pin dapat tersembunyi karena oklusi/frustum/ruang penempatan kurang. Enam pilihan panel tetap tersedia dan seluruhnya sudah dibuka dalam smoke. Tidak menambah solver, memaksa semua pin terlihat, atau mengubah framing model di T4.4.
