# T4.19: Close About tidak menutupi tautan

30 Oktober 2026, Asia/Jakarta. Validasi disetujui, kemudian planning disetujui dan implementasi diminta Barkah. **Acceptance final diterima 30 Oktober 2026:** Barkah mengonfirmasi sudah mengecek T4.19 dan lolos, meminta task serta tiga checklist selesai, pembaruan dokumen dan commit/push ke develop. Anak body tidak menyusut; overscroll ditahan dalam body. Judul dapat membungkus pada teks besar. Lebar existing dan batas85vh/85dvh tetap.
- Aturan baru dibatasi `#about`; hapus sticky Close yang hanya dipakai About. Dialog Simpan/Hapus tetap memakai layout lama. Tidak mengubah JavaScript aplikasi, konten/URL/i18n, API/skema, dependency, model, aset atau analytics.
- Arah Industrial Safety Studio, ENERGY1/RHYTHM1/MOTION1. Kuning menandai aksi Tutup, header/body terpisah secara layout agar konten tidak bersaing dengan kontrol. Spacing/font/radius/warna tetap token existing; tidak menambah animasi.

## Alat dan batas

Browser Use doctor gagal daemon/koneksi sehingga memakai Chrome/Playwright lokal existing. Tidak install dependency. Probe synthesizeScrollGesture tidak menghasilkan gulir yang diharapkan; diganti urutan touchStart/Move/End. Probe penutupan segera setelah swipe sempat timeout; versi final menunggu scroll stabil200ms, lalu tap/fokus kembali lolos. Tidak ada perubahan aplikasi untuk mengatasi probe. Contact sheet gagal karena Pillow tidak tersedia; seluruh screenshot ditinjau langsung, tidak menginstall paket. Kegagalan tersebut tidak dihitung PASS.

Matriks memakai reduced motion; input tambahan memakai preferensi motion normal. Teks200% menggandakan ukuran computed seluruh elemen About di browser QA, bukan zoom OS. HP fisik, AT/screen reader, Safari/Firefox, HTTP tujuan eksternal, Lighthouse/4G/FPS baru belum diuji. Dua tautan tel: dicegat tanpa memulai panggilan. Warning chunk utama>500KB existing tetap. Model tetap695.084 byte.
