## Hasil

- Overview default6kg mengisi sekitar68,20% area bebas desktop1280×900 dan70,41% mobile390×844/half, berdasarkan proyeksi bbox pada bridge debug. Screenshot normal tanpa debug juga ditinjau. Perhitungan aplikasi memakai bbox sebelum marker debug ditambahkan.
- Ukuran kapasitas tetap terlihat berbeda. Pada mobile, rasio bbox1/3/6/9kg sekitar45,77/57,73/70,41/78,88%; kamera tidak berubah saat kapasitas diganti. Bbox9kg/bracket tetap masuk area aman.
- Target orbit berada di pusat model. Helper menggunakan bbox6kg, FOV/aspek/area aman dan envelope skala maksimum dari product.json, termasuk ruang idle rotation. Jarak dicari dengan36 iterasi; tidak menambah renderer/loop permanen. Area nol tidak menghasilkan kamera invalid. Batas orbit minimal1,5 dipertahankan.
- Fit pertama sebelum splash dan resize overview memakai cameraTween immediate. Gesture start/end membandingkan posisi/target/zoom; tap tidak memindahkan kamera atau mengunci fit. Idle rotation nyata tetap otomatis. Orbit/wheel nyata mengunci view manual sampai reload/model baru. Resize selama gesture/kartu ditunda; Train/kuis tidak dikendalikan overview, dan snapshot tetap pulih.
- Body/kontrol panel16px, pendukung14px, judul20px/subjudul16px; token lama tetap berarti ukuran semula. Teks sekunder panel/dialog terkait memakai#B0B7C2. Tidak mengubah topbar, PDF, nomor pin, copy K3, data, storage atau analytics.
- Grafik Results memakai lebar SVG aktual sehingga font14px tidak menyusut; margin sumbu/tinggi plot mengikuti font200%. ResizeObserver hanya aktif selama Results dan dibersihkan saat exit.
- Bug visual yang ditemukan saat QA: pada mobile390/ID/teks200/peek, tombol rotasi setinggi114px mendorong judul pin ke y804–900, di luar batas isi828. Viewer-tools kini disembunyikan selama reader hotspot mobile dan pulih setelah Tutup; desktop tetap. Judul dan tombol Tutup lulus168 keadaan terpisah.

### Batas dan probe yang dikoreksi

- Browser Use doctor gagal daemon/koneksi; QA memakai Playwright/Chrome existing tanpa install paket.
- Probe khusus awal memakai selector PDF `#export-spec` yang tidak ada. Diganti dengan data-pdf existing dan unduhan sungguhan; laporan gagal dipertahankan di `t4.7-production-initial-qa.json`.
- Helper snap awal mengejar nama full walau half/full berimpit, lalu berpindah ke peek. Diganti pembandingan tinggi; laporan gagal di `t4.7-production-snap-initial-qa.json`.
- Regresi PASS awal punya selector telepon lama yang ambigu dengan chip topbar. Wrapper membatasi ke kontak training; laporan gagal di `t4.7-training-initial-qa.json`. Source task lama tidak diubah.
- Probe invariants awal membandingkan byte teks HEAD/LF dengan checkout/CRLF. Dikoreksi normalisasi baris teks saja; aset tetap dicek byte/hash. Tidak ada i18n yang diubah.
- Warning presisi shader Chrome headless existing dicatat terpisah, errors final kosong. Tidak ada bypass keamanan atau klaim HP fisik/Safari/Firefox/AT/zoom OS. Teks200 memakai token CSS.
- Landscape844×390 dapat menyisakan kanvas16px seperti sebelum task; tidak dinyatakan nyaman untuk model. Ruang deskripsi pada peek/teks besar terbatas dan tetap scroll, tanpa snap otomatis. Pada1024px/area sempit, keselamatan bbox mengalahkan sasaran70%. Kamera manual boleh keluar framing setelah perubahan aspek, sesuai pilihan pengguna.
