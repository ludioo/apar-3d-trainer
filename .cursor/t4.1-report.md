# T4.1: RoomEnvironment default

28 Oktober 2026. **Acceptance final diterima Barkah:** pengguna menyatakan sudah memvalidasi dan lolos, lalu meminta update dokumen dan commit/push ke develop saja. Task dan empat checklist ditutup; RoomEnvironment diterima sebagai default. Rincian perangkat tidak diberikan, sehingga tidak diklaim ada QA HP fisik/AT/browser baru. Hasil ukur dan batas di bawah tetap dipertahankan. Check/build diulang untuk penutupan sebelum commit, tanpa mengulang browser/Lighthouse karena aplikasi tidak berubah. T3.5 tetap ditunda, T4.2 belum dimulai dan main/produksi tidak diubah.

Riwayat implementasi: validasi Q1–Q3 dan planning disetujui sebelum implementasi. Penyerahan awal menunggu acceptance tanpa commit/push/deploy. Catatan menunggu acceptance tersebut ditutup oleh konfirmasi di atas; hanya perubahan dan bukti T4.1 disertakan dalam commit, perubahan lokal lain dipertahankan.

## Hasil pengukuran

Chrome 156.0.8078.49, build produksi lokal, server `t3.1-server.cjs` pada port 4191: gzip HTML/JS/CSS, binary tetap. Browser baru tiap run, cache dimatikan, viewport 390×844 DPR 1.75 dan sentuhan, download 9 Mbps/upload 1.5 Mbps, latensi 60 ms, CPU slowdown 4×. Tiga run berurutan per kondisi, tanpa debug. Umami tidak dimuat karena hostname localhost; bukan pengukuran produksi live.

| Kondisi | Transfer navigasi + resource, setiap run | APAR tampil per run | Median APAR |
|---|---:|---|---:|
| Sebelum perubahan, HDRI default | 2.323.375 byte | 3.947,4 / 4.075,6 / 3.794,1 ms | 3.947,4 ms |
| Sesudah perubahan, RoomEnvironment default | 1.135.426 byte | 3.426,0 / 3.485,1 / 3.349,3 ms | 3.426,0 ms |
| Sesudah perubahan, `?hdri=1` | 2.325.130 byte | 3.632,6 / 3.831,6 / 4.358,3 ms | 3.831,6 ms |

Transfer default turun **1.187.949 byte (51,13%)**. Median waktu tampil turun 521,4 ms terhadap baseline baru; **target <3 detik belum tercapai**. Sampel diambil setelah `apar:visible` dan jaringan tenang: Playwright networkidle 500 ms lalu 750 ms tambahan, sehingga idle minimum 1.250 ms, bukan tepat 750 ms. Semua resource sampai titik sampel dihitung bersama dokumen navigasi melalui Resource Timing. Tidak ada request tambahan selama interval tenang tersebut. Waktu tampil memakai timestamp navigasi mark `apar:visible`, bukan measure load yang baru dimulai sesudah initScene. Jalur gagal tidak dihitung sebagai APAR siap dengan environment.

HDRI encoded body tetap 1.187.546 byte; Resource Timing transfer 1.187.846 byte termasuk estimasi overhead. Default sesudah perubahan tidak memiliki preload, request HDRI, atau chunk HDRLoader. HDRLoader pembanding menjadi chunk tersendiri 3.280 byte, gzip server 1.558 byte. Addon RoomEnvironment tidak memerlukan gambar/aset unduhan, tetapi kodenya ikut bundle.

Laporan build Vite: main sebelum 826,41 KB / gzip 228,13 KB; sesudah 827,65 KB / gzip 227,92 KB. CSS tetap 29,36 KB / gzip 5,53 KB. Angka gzip Vite berbeda dari gzip Node default pada server audit: main 226.525 → 226.343 byte; jangan mencampur kedua metode. GLB tetap 695.084 byte. Warning chunk >500 KB existing tetap. Tidak ada perubahan dependency/lockfile, model, font, tekstur unduhan, atau skema storage.

Bukti mentah: `t4.1-before.json`, `t4.1-after.json`, `t4.1-hdri.json`; probe `t4.1-audit.cjs`. Audit Lighthouse menyeluruh tetap T4.25. Angka historis T3.1 dipertahankan dalam laporan lamanya, bukan dipakai sebagai baseline baru.

## Pilihan visual dan implementasi

RoomEnvironment dipertahankan sebagai default: pantulan lebih lebar dan merata, sementara body merah, aksen kuning, label, pin, tuas dan nozzle tetap terbaca. Pantulan silver lebih menyebar daripada HDRI; tidak dianggap padanan pantulan identik. Perbandingan menggunakan kamera/target, konfigurasi dan reduced motion sama pada desktop 1280×900 serta mobile 390×844. Exposure tetap 1, ACES/background/directional light/material asli tetap. Screenshot `t4.1-{desktop,mobile}-{room,hdri}-{red,yellow-bracket,silver-bracket,pin}.png`; capture PDF berupa `t4.1-*-capture.jpg`. Desktop dan HP emulasi ditinjau; perangkat fisik masih oleh Barkah.

PMREM fromScene memakai sigma 0, near 0.1/far 100, size 128 untuk pointer coarse / 256 pointer fine, ditentukan sekali saat startup. Atlas hasil yang diuji 384×512 untuk coarse dan 768×1024 untuk fine; angka tersebut bukan ukuran cube-face. Room/generator dan HDR sumber dibebaskan setelah konversi; hasil PMREM tetap sepanjang scene. Kontrak boolean serta mark sukses/gagal dan splash tetap. Gagal RoomEnvironment memakai directional light tanpa mengunduh HDRI. `?hdri=1` mempertahankan gzip → HDR asli serta fallback directional; pilihan lain memakai default. HDRI tetap tersimpan/dibangun untuk pembanding, tanpa transfer awal default.

## Verifikasi

- `npm run check`: 185 key EN/ID dan semua pemeriksaan existing lolos. Pemeriksaan environment menambah pilihan/preload, size coarse/fine, lazy HDRLoader, jalur tanpa DecompressionStream, gzip gagal, HDR gagal, mark/render dan disposal pada sukses/gagal.
- `t4.1-check.cjs` / `t4.1-qa.json`: 14 kelompok lolos. Empat kombinasi layar × environment memeriksa PMREM/exposure/background, orbit/zoom (mobile touch drag/pinch CDP), tiga warna/bracket, fokus/tutup pin, unduh PDF/capture, About EN/ID serta routing. Default dan `?hdri`, `?hdri=0`, `?hdri=true` tanpa preload/request/chunk HDR. Jalur HDR gzip gagal/asli berhasil, API dekompresi hilang, kedua HDR gagal, dan model gagal/Retry lolos. Kegagalan PMREM disuntikkan hanya pada respons modul dev (port 5191) untuk membuktikan integrasi fallback default tanpa HDRI.
- `t4.1-regression.cjs`: 11 kelompok PASS produksi di `t4.1-training-qa.json`, termasuk touch, keyboard/hold/six-stroke Sweep, restore konfigurasi/kamera, storage/Retry, reduced motion dan 40 kombinasi layout. Delapan kelompok efek di `t4.1-effects-qa.json` lolos: 24/72 partikel, nozzle, draw calls, burst/idle/padam, pause/resume dan resource stabil. FPS headless bukan bukti HP fisik.
- `t4.1-credits.cjs` / `t4.1-credits-qa.json`: desktop/mobile × EN/ID pada teks 200%, fokus keyboard terlihat, hit-test link baru, Enter membuka tab URL yang benar, Escape memulihkan fokus dan tanpa overflow halaman. Navigasi eksternal dicegat; bukan audit HTTP situs three.js.
- Empat PDF spesifikasi / delapan halaman dirender Poppler, empat halaman foto serta halaman teks bersama ditinjau. Halaman kedua identik secara piksel di seluruh PDF. `t4.1-pdf-check.py` / `t4.1-pdf-qa.json` membuktikan gambar 1200×900, margin seluruh glyph, red/bracket/6kg/harga USD41 dan disclaimer/darurat. Dua halaman adalah layout existing; perubahan menjadi satu halaman tetap T4.10.
- Tidak ada pageerror/console error tak terduga. Favicon 404 existing dan network failure yang sengaja disuntikkan dikecualikan secara eksplisit, bukan disembunyikan sebagai PASS jaringan normal.

Probe awal mobile memakai roda mouse yang tidak mengubah kamera pada emulasi touch. Hasil gagal disimpan `t4.1-qa-initial.json`, probe diperbaiki ke touch drag/pinch CDP dan seluruh run khusus diulang hingga lolos, tanpa mengubah aplikasi. Probe PDF awal perlu normalisasi whitespace hasil ekstraksi; sesudah koreksi semua pemeriksaan lolos. Poppler mengeluarkan warning konfigurasi font sistem yang tidak dipakai, tetapi exit 0, render/glyph/margin lolos. Browser-use doctor gagal daemon/koneksi; QA memakai Playwright/Chrome existing. Tidak memasang tool/dependency baru.

## Gate antislop untuk perubahan T4.1

Arah existing Industrial Safety Studio untuk demo calon klien dan pembelajaran APAR, ENERGY 1 / RHYTHM 1 / MOTION 1; antislop selama pengerjaan mengikuti keputusan sebelumnya. Tidak membuat ulang layout, typography atau motion.

- Hard Gate untuk perubahan ini PASS: IBL/APAR nyata, kredit/lisensi akurat, nilai performa hasil ukur; loading/error/Retry dipertahankan. Link kredit baru diuji keyboard/fokus/tab tujuan dan mobile/200%. Teks baru memakai style/link existing, tanpa token kontras baru.
- Purpose Gate PASS: IBL prosedural menurunkan transfer; studio gelap menjaga fokus pada produk, kuning tetap menandai kontrol/bagian. Tidak menambah dekorasi/aset generatif/toggle.
- Liveliness PASS pada cakupan lighting: APAR menjadi fokus, warna/surface studio dan aksen safety existing dipertahankan; pantulan tetap memberi bentuk pada silinder dan logam. Tidak menambah gerakan.
- Craftsmanship/Copy PASS pada perubahan: build/check dan click-through di atas; EN/ID konsisten, tanpa klaim load <3 detik. Kredit sumber terpisah antara environment default dan pembanding.

Ini bukan audit ulang seluruh aplikasi. Overlay tombol Tutup About existing tetap temuan T4.19; link baru dapat discroll ke tengah dan diakses dengan keyboard pada 200%. Masalah ukuran model/bottom sheet/pagination PDF existing tetap task berikutnya, tidak diklaim sudah diperbaiki.
