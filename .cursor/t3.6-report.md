Chrome 156.0.0.0, Lighthouse 12.8.2 existing. Mobile Slow 4G bawaan Lighthouse/simulasi, profile Chrome baru tiap run, tanpa debug. Server `t3.6-server.cjs` memakai implementasi gzip teks/no-store/binary unchanged T3.1 pada port 4196. Host `trainer.barkahmauludi.com` diarahkan 127.0.0.1 hanya dalam Chrome uji, tanpa perubahan DNS/hosts sistem. Origin sama untuk before/after. Snapshot before berasal build sebelum perubahan; after build kode baru dengan UUID QA sintetis, tidak memerlukan Website ID asli. Script asli cloud dimuat, semua request kolektor diintersep menjadi respons QA; tidak ada dashboard writes. Run Lighthouse tidak disertai browser QA/build lain.

Pengukuran APAR terpisah pada 9/1,5 Mbps, latency 60ms, CPU 4×, 412×823/DPR1,75, cache dimatikan, mark apar:visible. Transfer penuh memakai audit Lighthouse karena Resource Timing cross-origin tanpa Timing-Allow-Origin memberi transferSize 0 untuk tracker. Angka Resource Timing same-origin tetap disimpan dalam summary, bukan dianggap total penuh.

Profil awal yang bertepatan dengan check/build dipisahkan ke `t3.6-profile-initial/` dan tidak dipakai untuk angka ini.
