## Hasil dan cakupan

- Sembilan nilai kamus ID diperbarui: kontrol/catatan braket, kondisi warna tidak tersedia, catatan ilustrasi, hint tahan, ringkasan Aim, ringkasan braket pada simpanan, judul ulasan kuis dan sumber darurat.
- Hotspot pin/judul selang, PASS Pull/Sweep, serta penjelasan kuis q6/q7 memakai nozel/daftar periksa/Golongan C. Dokumen sumber diperbarui sebelum data; makna instruksi serta URL sumber faktual tetap. Ejaan nozel mengikuti KBBI VI Daring, https://kbbi.kemendikdasmen.go.id/entri/nozel.
- Aplikasi hanya mengubah nilai teks di src/i18n/id.json dan tiga JSON data. Kamus EN, key kamus, seluruh nilai EN data, identifier, koordinat/radius/kamera, kunci jawaban serta field nonterjemahan sama dengan HEAD. JavaScript, CSS, API, schema, dependency dan aset tidak berubah.
- Default ID Konfigurasi #{n} sudah benar. Nama EN Config #1, ID Konfigurasi #2 dan custom Gudang #1 dibuat lewat Save nyata, lalu dipertahankan setelah bahasa/refresh. Nama tersimpan adalah pengecualian pemindaian bahasa; tidak dimigrasi. Istilah pada soal kepanjangan PASS, singkatan, nama diri/produk/sumber dan identifier internal tetap.
- Arah visual existing Industrial Safety Studio dipertahankan, ENERGY 1/RHYTHM 1/MOTION 1. Tujuan perubahan hanya membantu pengunjung ID memahami istilah; tidak ada desain, warna, aset atau navigasi baru.
