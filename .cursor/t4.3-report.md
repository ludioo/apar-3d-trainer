## Perubahan dan baseline

Kode aplikasi hanya `src/ui/quiz.js` dan `src/ui/quiz.css`. Tidak ada dependency/aset/K3/data/skema storage/analytics baru atau perubahan sheet/3D. Perubahan lokal existing AGENTS.md, implementation-plan/prompts, library-research dan artefak task lain dipertahankan.

- Padding bawah nyata memakai tinggi footer yang diukur ResizeObserver existing + space-8. Scroll-padding mengikuti ukuran yang sama; Next tetap sticky dan target tombol minimal 44×44px. Heading mendapat scroll-margin-top.
- Feedback/status/sumber existing dipindah tepat setelah opsi terpilih, termasuk jawaban pin 3D. Iterasi opsi dibatasi tombol anak langsung, sehingga feedback tidak ikut dihitung sebagai opsi. Node feedback dipulihkan sebelum mengganti daftar pada soal berikutnya.
- Focus feedback memakai preventScroll tanpa scrollIntoView. ScrollTop dipertahankan selama render, scroll anchoring dimatikan khusus kuis, ruang hint tetap setelah jawaban agar pilihan tidak meloncat. Next/start/restart tetap fokus judul dari atas.
- `t4.3-before.json` dan dua screenshot before menunjukkan pada 390×844 ID/default half: scroll 0→254px; judul y508→254, di luar scroller y467–828. Opsi ketiga soal pertama masih utuh pada baseline; tidak mengklaim overlap terjadi di soal ini. Kamera pada screenshot awal masih dalam tween; gambar tersebut membandingkan UI, bukan ukuran/framing 3D.
- Probe sesudah perubahan serta laporan produksi: scroll 0→0 dan judul y508→508, feedback tepat setelah opsi a. Status Benar/Salah dekat jawaban; penjelasan/sumber tetap bisa digulir.

## Pemeriksaan final

Perintah yang dapat dijalankan ulang:

```text

node .cursor/t4.3-check.cjs http://localhost:5193 --fixture-only
node .cursor/t4.3-regression.cjs http://localhost:4193
node .cursor/t4.3-regression.cjs http://localhost:4193 --training --production
npm run check
npm run build
```

Server lokal memakai CLI Vite existing, dev 5193 dan preview produksi 4193, host 0.0.0.0. Script khusus otomatis memakai Chrome/Playwright existing; tidak memasang library.

- **Khusus produksi: empat kelompok PASS**, `t4.3-production-qa.json`, errors kosong. Baseline sesudah perbaikan; delapan soal via panel/skor 8/8; matriks 40 keadaan × delapan soal; serta keyboard/pin q2/q5.
- Matriks: 360×800, 390×844, 844×390 dengan tiga snap dan desktop 1365×900; EN/ID × token teks 100/200%. Memeriksa setiap opsi di delapan soal, sumber, footer, ukuran target, koordinat hit-test, penguncian, jawaban benar/salah, Next/ulang/skor dan tanpa overflow horizontal halaman. Teks 200% adalah simulasi token CSS, bukan browser/OS zoom; matriks memberi token global, screenshot tambahan membatasi token pada kuis.
- Eksposisi opsi untuk membaca dilakukan sebelum mengambil ukuran before. Jawaban memakai koordinat mouse/touchscreen secara langsung, tanpa locator auto-scroll. Sesudah input, ukuran diperiksa setelah dua rAF sebelum melakukan scroll lain: scroll dan posisi judul tetap dalam toleransi 1px, snap sama, feedback tepat setelah pilihan dan difokuskan. Next mengembalikan scroll 0.
- **104 kasus opsi tinggi** pada teks 200% di sheet pendek, termasuk half landscape: tinggi opsi melebihi ruang di atas nav. Awal/akhir isi dapat digulir dan target menerima input; tidak dihitung sebagai kotak yang terlihat penuh serentak. Untuk opsi yang muat, rect utuh di atas nav dan hit-test diwajibkan. Pada laporan raw tallOptions.height adalah tinggi opsi; viewport layar terdapat di states. Batas ini dipertahankan karena snap tidak boleh otomatis diperbesar.
- Keyboard memakai Enter/Space untuk jawaban, feedback menerima fokus, Tab mencapai Next dan Enter melanjutkan. q2 dijawab melalui pin dengan keyboard, q5 melalui native touch; keduanya benar dan skor akhir 8/8. Full completion panel menguji enam tombol alternatif hotspot.
- **Fixture empat opsi: satu kelompok PASS**, `t4.3-dev-fixture-qa.json`, errors kosong. UI disuntikkan ke panel pada konteks tes; opsi d memakai salinan teks c existing, diberi state UI terisolasi. Opsi keempat utuh/terkena tap, feedback setelah d dan scroll tetap. Tidak menambah soal atau jawaban pada data/mesin produksi.
- **Regresi kuis: tujuh kelompok PASS**, `t4.3-quiz-qa.json`, errors kosong. Skor 0/5/6/8, batas lulus, retry, simpan sekali/storage gagal/rusak, About/blur/bahasa/navigasi/refresh, model gagal/Retry, native touch kedua pin, reduced motion dan 60 keadaan layout existing. Script lama memakai auto-scroll untuk pemeriksaan keterjangkauan; bukti khusus di atas membuktikan tidak ada lompatan sesudah menjawab.
- **Regresi PASS: 11 kelompok PASS**, `t4.3-training-qa.json`, errors/failure kosong. Pull/Aim, keyboard/touch hold/Sweep, snapshot konfigurasi/kamera, interupsi, storage, tiga snap/60 keadaan layout, reduced motion dan model gagal/Retry. Bukan pengukuran performa/HP fisik baru.

Screenshot produksi feedback pertama, mobile half/jawaban salah dan desktop ditinjau. Tambahan `t4.3-text200.png` dan `t4.3-landscape200.png` menampilkan feedback setelah scroll manual pada sheet full dan teks kuis 200%. Teks asli tetap; pada viewport pendek scroll diperlukan. Tidak mengklaim semua isi muat serentak.

## Check, build, dan batas alat

Check PASS: 189 key i18n dan seluruh self-check existing. Build PASS: JS utama 829,30 KB / gzip 228,47 KB; CSS 29,74 KB / gzip 5,64 KB. Dibanding angka build T4.2 tercatat, tambahan gzip sekitar 0,06 KB JS + 0,05 KB CSS, total 0,11 KB (Vite membulatkan dua desimal; bukan build baseline ulang). GLB tetap 695.084 byte. Warning chunk utama >500 KB existing tetap.

Browser-use doctor gagal daemon/koneksi; fallback Playwright/Chrome existing. Npm dev tidak meneruskan argumen dengan benar di shell ini, sehingga CLI lokal dipanggil langsung. Regresi PASS pertama tanpa --production mencoba import source pada dist dan gagal; bukti dipertahankan di `t4.3-training-initial-qa.json`, run ulang final lengkap lolos.

Run dev awal (`t4.3-dev-initial-qa.json`) meloloskan 40 keadaan dan keyboard, lalu fixture gagal karena helper memakai mesin kuis produksi yang menolak ID d. Helper diperbaiki menjadi state UI terisolasi; pemeriksaan fixture terpisah diulang sampai lolos. Kegagalan helper bukan PASS penuh, tidak menyebabkan perubahan aplikasi, dan laporan awal tidak dihapus/ditimpa. Pemeriksaan produksi menggunakan kode aplikasi yang sama dan seluruh kelompoknya lolos. Timestamp metadata script regresi lama masih berisi tanggal asal 28 Okt; tanggal run ini 29 Okt sesuai laporan ini.

Tidak diuji: HP fisik, Safari/iOS, Firefox, AT/screen reader aktual, OS/browser zoom, audit Lighthouse/4G baru atau deployment produksi. Screenshot dan angka bukan klaim pengujian tersebut. Favicon 404 existing serta fault storage/model yang sengaja disuntikkan oleh regresi dipisahkan dari error aplikasi normal.

## Gate antislop untuk perubahan T4.3

Arah existing Industrial Safety Studio, ENERGY 1 / RHYTHM 1 / MOTION 1 untuk perubahan ini. Produk dan pilihan jawaban tetap fokus; aksen kuning untuk aksi, warna hasil disertai teks. Tidak menambah dekorasi/animasi/aset.

- Hard Gate: PASS untuk cakupan kuis yang diuji, dengan batas ruang/perangkat di atas. Konten K3/i18n tetap, opsi/status/sumber/Next berfungsi dan keyboard/touch diverifikasi. Kontras terhadap surface-solid: teks 15,87:1, muted 6,77:1, success 7,86:1, danger 5,77:1; tinta tombol terhadap kuning 12,01:1. Seluruhnya melewati AA; bukan audit ulang seluruh aplikasi/AT.
- Purpose Gate: PASS. Padding menghindarkan konten dari footer, feedback dekat pilihan mengurangi jarak baca, hint mempertahankan posisi dan fokus preventScroll menjaga konteks. Tidak mengubah tema/palet/tipografi global pada kode aplikasi.
- Liveliness: PASS dalam arah existing. APAR, urutan soal, hasil benar/salah dan CTA kuning tetap memberi hierarki; tidak ada template/elemen baru.
- Craftsmanship: PASS untuk cakupan dan keadaan yang tercatat. Bukti berupa geometry/hit-test, click-through, screenshot dan check/build. Opsi yang lebih tinggi daripada area baca tetap dapat digulir; tidak menyatakan semua opsi selalu tampak serentak.
